# モバイル実機の受け入れ確認

対象はiOS SafariとAndroid Chrome。機種、OSとブラウザの版、日時、URL、候補SHAを記録する。対象URLは https://bem130.github.io/quiz/ とし、公開SHAと版は #78 の記録を参照する。ユーザー指示によりPages公開を先行し、実機確認用の別経路は設けない。

desktopのWebKit、touch emulation、合成compositionイベントの成功を実機の結果として転記しない。既存のサイトデータを消す必要はない。公開されたPagesで確認用の草稿やユーザーを作る。

## 確認項目

| ID | 操作 | 期待する結果 |
| --- | --- | --- |
| M01 | 新規に開き、既定題庫を選んで出題する | 3題庫・5patternを読み込める。問題と2〜4個の選択肢、図が表示される。 |
| M02 | 縦持ち・横持ち、狭幅、文字拡大で操作する | 本文と選択肢を読める。SVG／SMILESは比率を保ち、ボタンや本文を覆わない。必要なスクロールとフォーカスが維持される。 |
| M03 | タップで解答、IDK、中断、再挑戦する | 誤操作による二重回答がない。保存中は次問・中断を追い越せず、結果は保存済み回答に対応する。再挑戦は新sessionで始まる。 |
| M04 | ユーザー名、題数、URLなどを画面キーボードで入力する | キーボードが入力中の欄と必要な操作を隠さない。値を設定切替で失わず、意図しないsubmitや回答shortcutが発動しない。 |
| M05 | 草稿を開き、標準入力でJSONを編集する | touch端末は標準textareaを利用できる。コピー・貼り付け・カーソル移動・選択・スクロールとpreviewが利用できる。 |
| M06 | OSの日本語IMEで変換中に切替・保存・閉じるを試す | 変換中は破壊的な切替を行わない。確定後に保存し、再openで確定した日本語が残る。不正JSONの編集途中も草稿として保持する。 |
| M07 | ファイルを編集後すぐ別ファイルへ移動し、元へ戻る | 直前の入力が元のファイルへ保存される。失敗時には元の入力を保持し、失敗を表示する。 |
| M08 | source previewから入力位置へ移動する | 同じファイルの対応位置へ移動し、入力内容や選択を壊さない。Monacoへの切替も未保存内容を処理してから行う。 |
| M09 | 読みの収集、共有URL、QR、出典を操作する | 右クリックやhoverに依存せず操作できる。共有した範囲が別の新規環境で再現され、QRの実機読取りも確認する。デスクトップのOS／VS Code連携は任意として別記録する。 |
| M10 | VoiceOver／TalkBackなどOSの読み上げを有効にする | 見出し・入力欄・ボタン・選択肢の名前とフォーカス順が操作に対応する。空欄・図の説明・正誤・保存中・エラーが理解でき、操作から抜けられる。 |
| M11 | 取得・保存後にofflineへ切替え、ブラウザを終了して再度開く | 保存済み題庫・図・草稿から起動し、標準入力で編集保存、出題、回答保存ができる。未取得の外部データは利用不可を表示する。 |
| M12 | 完全backupをダウンロードし、新規の確認環境で復元する | OSのファイル保存・選択が可能で、草稿・ユーザー・履歴・設定・取得済みSVGが復元される。元の通常利用データで無断の上書きを試さない。 |
| M13 | 次の通常Pages更新時に、更新前から開いていた端末のタブを維持し、更新確認で待機版を取得して学習・未保存編集・保存完了を確認する | 学習／未保存編集を強制reloadしない。準備失敗時は適用可能と表示せず、保存終了後の明示更新だけを行う。更新前後のSHAとversionも記録する。 |
| M14 | 学習中と草稿の保存完了後に、ホーム画面／別アプリへ切り替えて復帰する。OSが再読み込みした場合も別記する | 保存済み回答・草稿・ユーザーを保持し、二重回答や意図しないshortcutがない。単なる復帰、OSによる再読み込み、ブラウザの終了・再起動を区別する。 |

M13は待機版がある場合に確認できる。同じ版を開き直しただけで成功扱いにしない。次の通常更新がまだなければ「未実施・待機版なし」と記録し、確認専用のリリースや別公開経路は作らない。

## 記録形式

各行を「成功／失敗／未実施」で記録し、失敗時は操作、期待、実際、再現性を付ける。保存時は確認用のユーザーや草稿の名前を添え、個人の問題内容や認証情報を公開Issueへ貼り付けない。OSの中断・復帰、画面キーボード、実IME、読み上げはそれぞれ独立して記録する。

本書の作成は実機確認の完了を意味しない。実機結果が未記録の行は #72 の残件として保持し、OGPのユーザー更新待ちとは分けて扱う。
